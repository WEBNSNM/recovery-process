# 康程记录 MVP 设计（最终实现）

## 已确认目标
Vue 3 + Vite 前端与 Cloudflare Worker + D1 后端放在当前目录，所有健康记录通过接口保存。TheChosenOne 仅作为结构参考，代码、配置、数据库均独立。普通 Vue/Vite 不直接编译微信小程序，因此额外提供原生微信入口，复用 API、报告与校验模块。

## 模块
- `src/App.vue`：五个哈希导航页面，统一表单和错误反馈。
- `src/LineChart.vue`：单指标/单单位 SVG 折线、症状和用药变更标记。
- `src/domain.ts`：日期范围、持续天数、最高体温、文字报告与可编辑记录复制。
- `src/services/api.ts`：同源接口请求，不提供健康数据本地回退，接口失败明确报错。
- `server/index.ts`：CRUD、首页聚合、导出、原子导入、访问密钥保护。
- `server/schema.ts`：统一字段映射、白名单、日期/数值/关联校验。
- `migrations/0001_init.sql`：五张表，每条记录包含版本号。
- `miniprogram/`：原生页面、Canvas 曲线、接口录入与 JSON 文件导入导出。
- `scripts/build-mini.mjs`：从源 TypeScript 生成小程序共享报告与验证逻辑。

## 数据与历史
体温、用药方案、实际执行、化验、事件分表。导出对象包含 backupVersion=1，每条记录包含 schemaVersion=1。导入先验证全部记录、ID 和执行关联，然后通过 D1 batch 原子替换。所有删除需 UI 确认。

剂量或用法调整默认保留旧方案至生效日前一天，新方案从生效日开始；此前执行记录保留关联旧方案。录入错误可以选择修正原记录。同日起始日期的调整直接修正当日方案。开始、调整和停用事件按实际生效日期记录，避免历史报告使用当前剂量。

## 数据访问与部署
本地 D1 存于本项目 .wrangler/state，运行迁移即可建表，不需要 Cloudflare 登录。公网使用独立 D1，需自己的账号、新数据库 ID、迁移和部署；家庭共享密钥控制数据访问，未配置时不开放公网接口。无个人登录、推送和后台自动上传/分享。

## 验证
12 项自动化测试、前后端 TypeScript 检查、Vite 构建、原生共享模块生成，以及真实本地 D1 CRUD、历史调整、错误导入保留数据、备份往返验证。H5 体温保存/编辑/回填和趋势报告已页面实测。原生页面完成语法、事件绑定及表单逻辑检查；当前机器没有微信开发者工具，模拟器与真机编译尚未验证。
